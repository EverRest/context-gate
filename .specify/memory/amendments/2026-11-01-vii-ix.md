# Amendment 1.1.0: principles VII and IX

Date: 2026-11-01. Version change: 1.0.0 -> 1.1.0 (MINOR: two rules materially restated).

## Why

A review of the code found three places where the shipped behaviour differs from the text of the
constitution. In each case the code is the stricter and safer behaviour, so the text is amended
to match it and no code is weakened.

## Changes

1. **VII, exception logging.** Old: the full exception goes to the application log after
   redaction. New: exception messages and traces are not logged at all; one metadata-only note
   (receipt identifier, exception class, file basename, line) goes to the receipt channel.
   Reason: a message can embed the value that caused it (a date parser quotes its input), and a
   redaction pass cannot know which part is data. Redaction of arbitrary text is the weakest tool
   the package has, so it must not guard the log.
2. **VII, what the model receives.** Old: a reason code and a receipt identifier. New: a generic
   message, plus a receipt identifier for errors; the reason code stays in the receipt. Reason:
   principle III already requires a hidden tool to look the same as a missing one, and a reason
   code per refusal would let a caller probe the configuration.
3. **IX, network in tests.** Old: no test may use the network. New: no test run by
   `composer test` may; the install matrix runs as its own CI job and its PHPUnit wrapper is
   opt-in. Reason: installing fresh Laravel 12 and 13 skeletons is the only way to prove the
   quick start works, and it cannot run offline.

## Affected specifications

- `specs/002-context-firewall/spec.md`: the "Constitution divergences" section is resolved.
- `specs/007-configuration/research.md`: rationale wording.
- `CLAUDE.md`: constitution version.

## Decision

Accepted by the maintainer on 2026-11-01.

## Clarification (not a text change)

Principle IV covers tool calls. A `429` answered by the HTTP refusal throttle before authentication is not a tool call,
so it does not write a per-call receipt; it writes one `http.throttled` receipt per client per window (caller
`unknown`, no IP).
